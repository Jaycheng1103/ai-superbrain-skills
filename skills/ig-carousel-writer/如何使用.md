# IG 輪播圖文：學員使用說明

版本：2026-09-19 學員版。

先看 [安裝與開始](references/安裝與開始.md)。GitHub repo 名稱是 `superbrain-ig-carousel-writer`，實際 skill 名稱是 `ig-carousel-writer`。

## 直接複製這句開始

> 用 ig-carousel-writer。把這篇文章規劃成 6 頁輪播，先給逐頁文案、Caption 與素材清單。沒有圖片的頁面列出待拍需求。

接著貼上你的素材。你可以補充兩三段本人作品讓 AI 校準語氣，沒有也能開始。故事、數字與成果只用自己的真實來源；沒有就直接說沒有。

## 如何修改

- 「保留我的原始觀點，第二段換成具體步驟。」
- 「這句不像我平常講話，請用較自然的台灣口語。」
- 「不要新增故事、數字、贈品或 CTA。」
- 「只修改指定段落，其餘完整保留。」

## 使用範圍

交付的是可修改初稿。寫作方法不保證流量、完播或成交；你需要核對真實性與公開範圍，再決定發布。素材不足時先做有根據的內容，不為篇幅補造經驗。

先選「只要文案／規劃」或「製作成圖」。成圖需要可用的圖片工具；以真實素材解釋觀點，缺圖先列拍攝清單。規劃完成不等於 PNG 完成。
