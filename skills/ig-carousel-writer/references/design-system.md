# 輪播設計與素材對應

這是製作建議，並非平台強制規格，也不代表任何參考作者的官方方法。沿用學員品牌與指定參考；沒有品牌時暫以純白底、近黑字、灰色輔文開始。

## 依內容選畫面

| 想解釋的內容 | 建議呈現 |
|---|---|
| 操作位置 | 真實介面局部、圈選、短標註 |
| 同一操作的差異 | 相同欄位與裁切的前後對照 |
| 步驟 | 同一場景逐頁加註 |
| 抽象關係 | 熟悉物件的比喻，交代映射與限制 |
| 判斷或原則 | 有情境與例子的簡潔文字頁 |
| 資源用途 | 可使用的原始封面與名稱，保留必要署名 |

每頁先寫明圖片在解釋什麼。照片不能替效果數字背書；模擬介面不能稱為產品截圖。沒有素材可用文字頁或列拍攝清單，不用泛用 AI 背景充數。

## 排版起點

1080 × 1350 畫布可從 72–88px 安全邊界、48–64px 標題、30–40px 正文開始。這些是起點，需在約 360px 寬預覽讀回。必要文字不裁切；字太多就拆頁或重寫，不把關鍵資訊縮成無法閱讀的小字。

以留白、對齊、字重和細分隔線組織內容。允許純文字頁與大留白，不要求填滿畫面、每頁放頭像、套 Tweet Card 或加金句盒。圖片保留自身比例與必要上下文。

## 一套保持一致

同一對照沿用構圖、裁切和標籤位置。同顏色與符號全套保持同義，搭配文字，不只依靠紅綠分辨。箭頭起終點明確，與實際物件對齊。

指定參考時先實看，再比較閱讀順序、字級、留白與素材作用；不要只換背景色就宣稱符合參考。參考作品留在研究資料，不把原作者圖片放入可發布資料夾。
