# 輪播交付模板

用目前專案指定的資料夾；沒有指定就建單一 `carousel-日期-主題/` 內容包。獨立研究、既有主稿與可發布輸出分開。

## README.md

- 主題、受眾、來源主稿、核心訊息、品牌依據、此次輸出範圍。
- 已完成與未完成：規劃／圖片生成／文字校對／視覺驗收／發布，分別記錄。
- 檔案清單、版本與日期、原始來源、待補素材／待確認主張。

## 輪播逐頁文案.md

每頁包含以下欄位，不把整套寫成只有標題的點子清單：

```text
頁碼與功能：01／封面或直接對照
讀者這頁要理解的事：
標題（成品精確文字）：
正文／標註（成品精確文字）：
主張來源：主稿段落或來源 ID
素材 ID 與作用：不是「放一張照片」，要說圖片在解釋什麼
版型與閱讀順序：物件 → 標籤 → 結論等
裁切／留字區／標註位置：
跨頁延續：沿用哪頁的底圖、哪些標記新增或移除
保留項：原始文字、數字、人物、Logo 等
素材狀態與缺件：已確認／僅研究／待拍／待授權／生成示意
```

純文字頁也寫素材欄：`無圖片；以定義／例子分區解釋`，不用虛構素材 ID。

## 素材帳本.md

依 `real-world-assets.md` 的欄位填表。僅有規劃但尚無實體檔案時，本地路徑寫「待提供／待取得」；不能杜撰一個存在的路徑。另列拍攝清單及待確認資訊。

## 製作規格.md／prompt.md

記錄尺寸、暫定或已確認品牌、素材用途、版型、精確文案、參考圖傳入方式及保留項。每頁一份可執行指令；不要只寫「模仿某人風格」。

```text
用途：IG 4:5 圖解第 03 頁
此頁作用：指出同一物件上兩個區域的差別
輸入：A01 為實際編輯目標；A02 為插入素材（若有）
構圖：主體保留完整辨識特徵；文字與物件不互相覆蓋
標註：箭頭從「精確標籤」指到指定區域，不額外添字
精確文案：「……」
保留：列出不能修改的來源內容
可改：列出使用者已允許的處理
來源／真實性：原件或生成示意，明確標記
輸出：slide-03.png；舊版另存
```

## Caption 與圖片

`caption.md`：情境補充、必要署名／來源與一個真實可行的行動。用自然段落，不強迫 Emoji 與 hashtags。

要求成圖時交 `exports/slide-01.png` 到 `slide-NN.png`、`contact-sheet.jpg` 和 `QA.md`，保留可重製的排版來源或工具編輯指令。原始素材留 `assets/originals/`，生成或編輯結果留 `assets/derived/`。逐頁記錄視覺檢查、錯字修正與未解決事項。

僅規劃時不需要空白 exports，也不需要假的 QA 圖片通過記錄。
