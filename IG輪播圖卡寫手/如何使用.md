# IG 輪播圖卡寫手 · 學員使用說明

一支幫你把「一個主題」做成 5–10 張 Instagram 輪播圖卡的 AI skill。產出文案 + 可截圖的 HTML 圖卡 + Caption，套用 Schoger 設計原則（大字、滿版、色塊），視覺直接專業化。會用「你的品牌配色」生成。

---

## 怎麼安裝
把 `ig-carousel-writer/` 資料夾（或老師給的 `.skill` 檔）放到你的 skill 目錄：
- **Claude Code**：放到 `.claude/skills/` 或 `~/.claude/skills/`
- **Claude 桌面／網頁版**：用「上傳 skill」功能上傳

## 怎麼使用（兩步）
1. **填品牌設定**：打開 `ig-carousel-writer/references/品牌設定模板.md`，填你的配色、IG 帳號、頭像，貼回給 AI（最少填「主色」一個就能跑）。
2. **給它主題**：說「把 ___ 做成 IG 輪播」，附上素材。

它會產出每張圖卡的 HTML、Caption，還有一個 `build.sh`。

## 怎麼把 HTML 變成圖片（PNG）
圖卡是 HTML，要截圖成圖片才能發 IG。在圖卡資料夾裡執行一次：
```
npm i playwright && npx playwright install chromium   # 第一次才要
bash build.sh
```
跑完每張 `slide-XX.html` 旁邊會多出 `slide-XX.png`，那就是可以直接發的圖。

## 小提醒
- 第一次做先確認顏色對不對——如果出來還是預設深藍金，表示品牌設定沒吃到，重貼一次。
- 頭像把圖檔放進 skill 資料夾再填路徑；沒有頭像 AI 會用主色圓圈占位。
