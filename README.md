# AI 超級大腦流量學 · Skill 工具包

> 把你過去的經歷、你的聲音、你的品牌，變成一台會自己產內容的機器。
> 這裡放的是課程配套的 AI skill，下載 → 上傳 → 一句話就能用。

---

## 📦 內含 5 支 Skill

| Skill | 它幫你做什麼 | 下載 |
|------|------------|------|
| **五大選題產生器** | 從你自己的人生挖出 29 個專屬文章選題 + 標題 | [`topic-finder.skill`](五大選題產生器/topic-finder.skill) |
| **FB 長文寫手** | 把一個主題寫成 1500–3000 字、讀到最後的臉書長文 | [`fb-post-writer.skill`](FB長文寫手/fb-post-writer.skill) |
| **短影音腳本寫手** | 一個素材批量產 3–20 支高完播率短影音腳本 | [`reels-script-writer.skill`](短影音腳本寫手/reels-script-writer.skill) |
| **IG 輪播圖卡寫手** | 把主題做成 5–10 張你品牌配色的 IG 輪播圖卡（含 HTML） | [`ig-carousel-writer.skill`](IG輪播圖卡寫手/ig-carousel-writer.skill) |
| **Threads 爆文模板教練** | 用 20 個爆文模板，把故事／選題變成 Threads 串文 | [`threads-template-coach.skill`](Threads爆文模板教練/threads-template-coach.skill) |

每個資料夾裡都有一份 `如何使用.md`，點進去看該支 skill 的詳細用法。

---

## ⬇️ 怎麼下載

**方法 A：抓單一 skill**
點上表的 `.skill` 連結 → 右上角「Download raw file」。

**方法 B：一次抓全部**
這個頁面右上角綠色 **Code** 按鈕 → **Download ZIP**，解壓縮後就有 4 支 skill。

> 也可以到 [Releases](../../releases) 直接下載打包好的 `.skill` 檔。

---

## 🔧 怎麼安裝

把 `.skill` 檔（或解壓後的資料夾）放進你的 skill 目錄：

- **Claude Code**：放到專案的 `.claude/skills/`，或全域 `~/.claude/skills/`
- **Claude 桌面 / 網頁版**：用「上傳 skill」功能上傳 `.skill` 檔

放好後，新開一個對話就能用。

---

## 🚀 怎麼開始

每支 skill 第一次用，都會先請你提供一點「你自己」的資料（你的故事 / 語感 / 品牌配色），這樣產出來的才是「你的」內容，不是套版罐頭。照著它問的填就好。

裝好後試試這幾句：
- 「幫我想選題」→ 五大選題產生器
- 「把這個主題寫成 FB 長文」→ FB 長文寫手
- 「這個主題幫我做 5 支短影音」→ 短影音腳本寫手
- 「把這個做成 IG 輪播」→ IG 輪播圖卡寫手
- 「把這個故事寫成 Threads」→ Threads 爆文模板教練
