## ⬇️ 怎麼安裝（兩種方式擇一）

**方式 A：從 GitHub 一鍵匯入（最推薦）**
在 Manus 或 Claude 的「從 GitHub 匯入技能」貼上上表對應的網址 → Import。
（每支 skill 是獨立 repo、`SKILL.md` 在根目錄，匯入器才認得。）

**方式 B：下載 `.skill` 檔上傳**
到 [Releases](../../releases) 下載打包好的 `.skill` 檔，再用「上傳 skill」放進你的 skill 目錄：
- **Claude Code**：放到 `.claude/skills/`，或全域 `~/.claude/skills/`
- **Claude 桌面 / 網頁版 / Manus**：用「上傳檔案」上傳 `.skill`

放好後，新開一個對話就能用。

---

## 🚀 怎麼開始

每支 skill 第一次用，都會先請你提供一點「你自己」的資料（你的故事 / 語感 / 品牌配色），這樣產出來的才是「你的」內容，不是套版罐頭。照著它問的填就好。

裝好後試試這幾句：
- 「幫我想選題」→ 五大選題產生器
- 「把這個主題寫成 FB 長文」→ FB 長文寫手
- 「這個主題幫我做 5 支短影音」→ 短影音腳本寫手
- 「把這個做成 IG 輪播」→ IG 輪播圖卡寫手
- 「把這個故事寫成 Threads」→ Threads 爆文模板教練
